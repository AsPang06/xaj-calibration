# 手动复现指南

目的：不依赖任何缓存，从数据重算一遍「率定 → 分析 → 图件 → 报告」，并用自检脚本确认结果与交付稿一致。
适合提交前自查、或答辩现场按步骤演示。

预计总耗时：**约 2.5~3 分钟**（本机实测 160 秒：率定 139 s，分析 3.7 s，图件 9.7 s，报告 4 s）。

---

## 0. 先确认解释器（最容易踩的一步）

Windows 上可能同时存在多个 Python。本项目用到 **pandas**，系统自带的 `python` 未必有：

```powershell
python -c "import pandas"     # 报 ModuleNotFoundError 就说明不能用它
```

推荐直接用开发本项目时的解释器：

```powershell
$PY = "C:\Users\33917\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
& $PY -c "import sys,numpy,pandas,docx,PIL;print(sys.version.split()[0], numpy.__version__, pandas.__version__)"
```

预期输出：`3.12.14 2.3.5 3.0.1`。

之后所有命令都用 `& $PY scripts\xx.py` 的形式。

## 1. 备份现有产物（可选，但推荐）

```powershell
cd D:\新安江模型\xaj-calibration
```

## 2. 四步重算

逐条执行，等上一条跑完再下一条。用 `Measure-Command` 可以顺便看到耗时。

### 2.1 率定（约 2~3 分钟，本机 139 s）

```powershell
Measure-Command { & $PY scripts\01_calibrate.py }
```

预期关键输出：


```powershell

```

预期：7 行 `saved ...\outputs\figures\fig0N_....png`。

### 2.4 报告（约 5 秒）

## 3. 自动比对（关键一步）

```powershell
& $PY scripts\05_verify.py
"exit=$LASTEXITCODE"
```

预期最后一行：

```text
共 66 项，全部一致 —— 复现成功。
exit=0
```

这一步会把目标函数、16 个参数、四场 DC/RMSE/洪峰/径流深、行为参数集统计、7 张图、报告结构
逐项和交付稿比对（数值容差 1e-9）。**只有全 PASS 才算复现成功**。

若出现 FAIL：把那一行贴给我。最常见原因是换了 Python 依赖版本（numpy/pandas 不同版本会有末位差异）。

## 6. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `ModuleNotFoundError: pandas` | 用了系统自带 python | 用第 0 节的 `$PY` |
| 控制台中文乱码 | 代码页不是 UTF-8 | 先执行 `chcp 65001` |
| 01 长时间无输出 | DE 每 50 代才打印 | 等到 2 分钟左右 |
| `05_verify` 报 FAIL，数值只差 1e-6 量级 | 依赖版本不同 | 容差是 1e-9，属可解释差异；把 FAIL 行发我 |
| 04 报 `FileNotFoundError: fig0N` | 跳过了 03 | 严格按 01→02→03→04 顺序 |
| unittest 一片红色 | stderr 输出 | 看最后一行是否 `OK` |
| `scripts\reproduce.ps1` 无法执行 | 执行策略限制 | 命令前加 `powershell -NoProfile -ExecutionPolicy Bypass -File` |

